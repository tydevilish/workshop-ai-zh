เวิร์กช็อป: ปั้นเว็บข้อสอบ HSK ระบบ 3 ทักษะด้วย AI

มาสร้างเว็บจำลองการสอบ HSK แบบ Full Option!
จัดเต็มทั้งระบบ ฟัง (มีเสียงอ่าน), อ่าน, และเขียน ทีละสเตปให้ทุกคนมีส่วนร่วม

💡 ก่อนเริ่มงาน (คำศัพท์น่ารู้):
  • JSON: กล่องใส่ข้อมูลที่คอมพิวเตอร์อ่านง่าย แบ่งช่องชัดเจนว่าอันไหนคำถาม อันไหนตัวเลือก
  • HTML: โครงสร้างของหน้าเว็บ (เสาและหลังคา)
  • Tailwind CSS: ชุดตกแต่งเว็บสำเร็จรูป ช่วยระบายสีและจัดหน้าให้สวยเป๊ะแบบแอปมืออาชีพ
  • Web Speech API: ระบบอ่านออกเสียง (Text-to-Speech) ที่ฝังอยู่ในเบราว์เซอร์ เราจะใช้ตัวนี้สร้างเสียงจำลองให้ข้อสอบพาร์ทการฟัง

เราจะค่อยๆ ประกอบร่างเว็บขึ้นมา เพื่อให้ทุกคนได้เห็นกลไกการทำงานเบื้องหลังของแอปพลิเคชัน

2สร้างหน้าตาเว็บ (UI) วาดหน้าเริ่มสอบ และสร้างโครงสำหรับแสดงข้อสอบทั้ง 3 หมวด
3ติดระบบเสียง & แผงข้อสอบ ภารกิจพิเศษ! สั่ง AI เพิ่มปุ่มกดฟังเสียง และแผงข้อสอบ (Palette)
4ระบบตรวจคะแนน เพิ่มตัวจับเวลา และหน้าสรุปผลการสอบอย่างละเอียด

Step 1: ให้ AI สร้างข้อสอบ 3 หมวด (สร้าง JSON)

Prompt 1 (แนบไฟล์คำศัพท์ PDF/Word ไปด้วย)

เป้าหมาย: เตรียมข้อมูลดิบ (Data)
ข้อสอบ HSK มี 3 พาร์ทหลัก เราจะสั่งให้ AI นำคำศัพท์มาแต่งข้อสอบทั้งแบบ ฟัง (ต้องมีข้อความให้อ่านออกเสียง), อ่าน, และเขียน (ให้พิมพ์พินอิน)
🔥 ภารกิจ: เปลี่ยนตัวเลข [👉 ใส่จำนวนข้อ 👈] เป็นจำนวนข้อสอบที่ต้องการ 
ฉันมีไฟล์คำศัพท์ภาษาจีน (แนบไฟล์มาให้แล้ว)
จงสวมบทบาทเป็นอาจารย์สอนภาษาจีนระดับมืออาชีพ ช่วยแต่งข้อสอบ HSK จำนวน [👉 ใส่จำนวนข้อ 👈] ข้อต่อ 1 หมวด 
โดยแบ่งข้อสอบออกเป็น 3 หมวด ได้แก่:
1. listening (การฟัง) - เป็นปรนัย 4 ตัวเลือก มีประโยคให้ฟัง (audio) และคำถาม (question)
2. reading (การอ่าน) - เป็นปรนัย 4 ตัวเลือก เติมคำในช่องว่าง
3. writing (การเขียน) - เป็นอัตนัย ให้คำแปลมาแล้วให้ผู้สอบพิมพ์อักษรจีนตอบ

โปรดจัดเรียงผลลัพธ์ในรูปแบบ "JSON" โดยใช้โครงสร้างเป๊ะๆ ตามนี้:

{
  "listening": [
    { "id": 1, "audio": "ประโยคสนทนาภาษาจีน...", "question": "คำถาม...", "choices": [ {"label": "A", "zh": "ตัวเลือก A"}, ...ถึง D ], "answer": "A", "expl": "เฉลยสั้นๆ" }
  ],
  "reading": [
    { "id": 11, "question": "คำถามเว้นช่องว่าง...", "choices": [ {"label": "A", "zh": "ตัวเลือก A"}, ...ถึง D ], "answer": "A", "expl": "เฉลยสั้นๆ" }
  ],
  "writing": [
    { "id": 21, "question": "พิมพ์คำศัพท์ภาษาจีนที่มีความหมายว่า: [คำแปล]", "py": "พินอินของคำตอบ", "answer": "อักษรจีนที่ถูกต้อง", "expl": "เฉลย" }
  ]
}

กฎเหล็ก: ตอบกลับมาเป็น Code Block ของ JSON เพียงกล่องเดียว ห้ามมีคำอธิบายใดๆ ทั้งสิ้น
✅ สิ่งที่ต้องได้: กล่องโค้ด JSON ที่แบ่งเป็น 3 หมวดชัดเจน กดปุ่ม "Copy" เตรียมไว้เลย
ผลลัพธ์ที่ได้จาก AI จะเป็นกล่องโค้ด JSON ที่มีข้อมูลครบทั้ง 3 หมวด (ฟัง, อ่าน, เขียน) ให้กดคัดลอกเตรียมไว้เลย

Step 2: สร้างหน้าตาเว็บ และโครงข้อสอบ (UI & Layout)

Prompt 2 (สำหรับสร้างโครงเว็บ)

เป้าหมาย: สร้างบ้านให้ข้อสอบอยู่
สั่งให้ AI นำข้อสอบมาลงในเว็บ โดยสร้าง "หน้าเริ่มสอบ" ที่ให้กรอกชื่อ และสร้าง "หน้าทำข้อสอบ" ที่มีแท็บสลับระหว่าง การฟัง / การอ่าน / การเขียน
คำแนะนำ: ลบข้อความ [👉 วางข้อมูล...] ออก แล้ววาง JSON จาก Step 1 ลงไปแทน 
ช่วยสร้าง Web App แบบทดสอบ HSK ให้ฉัน โดยเขียนจบในไฟล์ HTML ไฟล์เดียว
ไม่ต้องแยกไฟล์ ฉันจะเปิดเล่นในเบราว์เซอร์โดยตรง

## ข้อมูลข้อสอบ (DATA)
นำข้อมูล JSON นี้ ฝังในตัวแปร JavaScript ชื่อ `EXAM_DATA`

[👉 วางข้อมูล JSON ที่ก๊อปปี้มาจาก Step 1 ตรงนี้ 👈]

## ดีไซน์เว็บ (ใช้ Tailwind CSS ผ่าน CDN)
- **สำคัญเรื่องฟอนต์:** ให้ดึง Google Fonts ชื่อ "K2D" มาใช้เป็นฟอนต์หลักของหน้าเว็บ เพื่อให้แสดงผลภาษาไทยได้สวยงามทั้งบน Mac และ Windows
- ใช้พื้นหลังสีครีมอ่อน (#fdf8f5) ข้อความหลักสีเทาเข้ม
- ปุ่มหลักใช้สีส้ม (#d35400) และดีไซน์การ์ดมุมโค้ง (rounded-2xl) พร้อมเงาดูทันสมัย

## ฟีเจอร์เวอร์ชัน 1: โครงสร้างและแท็บ
1. **หน้าจอเริ่มสอบ:** มีชื่อเว็บ มีกล่องให้ "กรอกชื่อผู้สอบ" และปุ่มเริ่มสอบ
2. **หน้าทำข้อสอบ:** 
   - มีแท็บ (Tabs) ด้านบน 3 อัน: "🎧 การฟัง", "📖 การอ่าน", "✍️ การเขียน"
   - เมื่อกดปุ่ม "ถัดไป" เรื่อยๆ ระบบจะเปลี่ยนจากหมวดฟัง ไปอ่าน ไปเขียน อัตโนมัติ
   - หมวดฟัง/อ่าน: แสดงคำถาม และปุ่มตัวเลือก 4 ข้อ (คลิกเลือกได้)
   - หมวดเขียน: แสดงคำถาม และมี "ช่อง Input (Text)" ให้พิมพ์ตอบ

กฎ: ห้ามใช้ <script type="module"> และ ห้าม fetch ข้อมูลจากภายนอก ส่งโค้ดมาเป็นก้อนเดียว
✅ ลองนำโค้ดที่ได้ไปเซฟเป็นไฟล์ exam.html แล้วเปิดดู เราจะได้เว็บที่มีแท็บ 3 หมวดแล้ว! (แต่พาร์ทฟังยังไม่มีเสียงนะ)
1. หน้าแรกสำหรับกรอกชื่อผู้สอบ
2. แท็บการฟัง (Listening) พร้อมตัวเลือก 4 ข้อ
3. แท็บการอ่าน (Reading)
4. แท็บการเขียน (Writing) พร้อมช่องให้พิมพ์ตอบ
5. โครงสร้างผลสอบเบื้องต้น

Step 3: ใส่ระบบเสียงและแผงควบคุม (Interactive Features)

Prompt 3 (พิมพ์คุยต่อในแชทเดิม)

เป้าหมาย: ติดตั้งฟังก์ชันที่ทำให้เว็บเหมือนแอปจริง
นี่คือจุดเด่นของเว็บเรา! เราจะใส่ "ปุ่มฟังเสียง" ในหมวดการฟัง และสร้าง "แผงข้อสอบ (Palette)" เพื่อให้ผู้สอบกดดูว่าข้อไหนทำแล้วหรือยังไม่ได้ทำ 
ยอดเยี่ยมมาก! ตอนนี้ฉันต้องการเพิ่มฟังก์ชันการโต้ตอบ (Interactive) เข้าไปในโค้ดเดิม
โปรดอัปเกรดโค้ดแล้วส่งโค้ด HTML เวอร์ชันใหม่มาให้เต็มๆ ไฟล์

ฟีเจอร์ที่ต้องเพิ่ม:
1. **ระบบอ่านออกเสียง (Text-to-Speech):** ในข้อสอบหมวด "การฟัง" ให้เพิ่มปุ่ม "▶ ฟังเสียง" ไว้เหนือคำถาม เมื่อกดปุ่ม ให้ระบบใช้ `window.speechSynthesis` อ่านข้อความภาษาจีนที่อยู่ในช่อง `audio` ของ JSON ออกมา (ให้ตั้งค่าเสียงเป็นภาษาจีน 'zh-CN')
2. **แผงข้อสอบ (Question Palette):** สร้างปุ่มเล็กๆ ด้านล่างจอที่กดแล้วจะมี Pop-up แสดงปุ่มหมายเลขข้อสอบทั้งหมด (กริดตาราง)
   - ข้อไหนที่เลือกคำตอบ/พิมพ์ตอบแล้ว ปุ่มหมายเลขนั้นให้เปลี่ยนเป็น "สีส้มทึบ"
   - ข้อไหนยังไม่ได้ตอบ เป็นขอบสีเทา
   - สามารถคลิกที่หมายเลขข้อเพื่อกระโดดไปทำข้อนั้นได้ทันที

กฎยังเหมือนเดิม: รวมทุกอย่างในไฟล์เดียว ห้ามตัดแบ่งโค้ดเด็ดขาด
✅ นำโค้ดไปเซฟทับไฟล์เดิม ลองเปิดแล้วเข้าหมวดการฟัง กดปุ่มเพื่อฟังเสียง AI พูดภาษาจีนได้เลย!
เพิ่มปุ่ม "▶ ฟังเสียง" ในหมวดการฟัง เมื่อกดจะมีเสียงอ่านภาษาจีนออกมา
เพิ่มแผงข้อสอบ (Palette) ช่วยให้ดูง่ายว่าข้อไหนทำแล้วหรือยังไม่ทำ

Step 4: จับเวลาและตรวจข้อสอบ (Scoring System)

Prompt 4 (พิมพ์คุยต่อในแชทเดิม)

เป้าหมาย: บทสรุปของการทำเว็บสอบ
สเตปสุดท้าย เราจะใส่ระบบจับเวลา เมื่อหมดเวลาหรือกดส่ง จะตรวจคำตอบและแยกคะแนนให้ดูว่า ทักษะฟัง อ่าน เขียน ได้คะแนนเท่าไหร่บ้าง
🔥 ภารกิจ: เปลี่ยนตัวเลขเวลาใน Prompt ก่อนกดส่ง! 
เยี่ยมมาก! สเตปสุดท้าย เราจะทำระบบตรวจข้อสอบ
โปรดอัปเกรดโค้ดเดิม และส่งโค้ด HTML สมบูรณ์แบบ (Final Version) มาให้ฉัน

ฟีเจอร์ที่ต้องเพิ่ม:
1. **แถบจับเวลา:** มุมบนจอให้แสดงเวลาถอยหลังรวม [👉 ใส่เวลาสอบ เช่น 15 👈] นาที (เวลาเดินตลอดไม่ว่าจะอยู่แท็บไหน) เมื่อเวลาหมดให้บังคับส่งข้อสอบทันที
2. **หน้าจอผลสอบ (Result Screen):** เมื่อกดปุ่ม "ส่งข้อสอบ" (ในข้อสุดท้ายของหมวดเขียน) ให้ตัดเข้าหน้าสรุปผล
3. **รายละเอียดในหน้าผลสอบ:**
   - แสดงคะแนนรวม ตัวใหญ่ๆ (เช่น ได้ 10/15)
   - มีกล่องแยก 3 กล่อง แจ้งว่า: การฟังได้กี่คะแนน, การอ่านได้กี่คะแนน, การเขียนได้กี่คะแนน
   - แสดงรายการเฉลยทุกข้อ บอกว่าข้อนี้ตอบถูกหรือผิด และแสดงคำอธิบาย (จากช่อง expl ใน JSON)
   - มีปุ่ม "กลับสู่หน้าแรก" เพื่อสอบใหม่

เขียนให้ครบจบในไฟล์เดียว ห้ามตัดโค้ดกลางคัน
✅ สมบูรณ์แบบ! นำไปรันและทดสอบระบบทั้งหมดได้เลย
1. แถบจับเวลาถอยหลัง (Timer) ด้านบนจอ เมื่อหมดเวลาจะบังคับส่งข้อสอบอัตโนมัติ
2. หน้าจอสรุปผลสอบ (Result) แยกคะแนนตามหมวดทักษะชัดเจน
3. ระบบตรวจคำตอบ แสดงเฉลย และคำอธิบายจาก AI สำหรับข้อที่ทำผิด

กล่องเครื่องมือฉุกเฉิน (บรรทัดกู้ชีพ)

หากเปิดเว็บแล้วจอดับ หรือ AI พิมพ์โค้ดไม่จบ ให้ก๊อปปี้ข้อความนี้ไปสั่งให้ AI ซ่อมครับ:

ปัญหาที่เจอ ประโยคสำหรับสั่ง AI ให้ช่วยซ่อมโค้ด
เปิดมาแล้วหน้าจอขาวโพลน โค้ดที่ให้มาพอเปิดในเบราว์เซอร์แล้วหน้าจอขาวโพลน ไม่มีอะไรขึ้นเลย น่าจะมีบั๊กหรือพิมพ์ผิดไวยากรณ์ ช่วยตรวจสอบการอ้างอิงฟังก์ชันตัวแปร และส่งโค้ดที่ซ่อมแล้วมาให้ใหม่ทั้งหมด
AI พิมพ์โค้ดมาให้ครึ่งเดียว แล้วหยุด โค้ดถูกตัดกลางคัน พิมพ์โค้ดมาไม่ครบ โปรดเขียนโค้ดที่เหลือต่อจากบรรทัดสุดท้ายให้จบสมบูรณ์ในกล่องโค้ดเดียว (ห้ามแยกไฟล์เด็ดขาด)
คลิกปุ่มหรือระบบเสียงไม่ทำงาน ปุ่มบนเว็บหรือระบบเสียงกดแล้วไม่ทำงาน ช่วยตรวจสอบระบบคำสั่ง (JavaScript) และแก้ไขโค้ดให้กลับมาทำงานได้ปกติ
