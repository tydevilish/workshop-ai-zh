prompt นี้ทำงานยังไง

  • เขียนเป็นภาษาอังกฤษเพราะประหยัด token กว่าและ AI ทำตามได้แม่นกว่า แต่สั่งให้หน้าเว็บที่ออกมาเป็นภาษาไทย 
Build me a Chinese character writing-practice web app as ONE self-contained HTML file.
I am a Chinese language teacher. I cannot write or read code.
This app needs an internet connection every time it is opened, because it uses a small
open-source library with real, accurate stroke-order data — that is a deliberate trade-off
in exchange for accuracy over building an approximate version myself.

## OUTPUT REQUIREMENT
A single .html file. I will open it in a browser. No install, no build step, but it DOES
need internet access each time it runs (to load the library and character data below).

## LIBRARY
Include EXACTLY this one external script tag and nothing else external:
<script src="https://cdn.jsdelivr.net/npm/hanzi-writer@3/dist/hanzi-writer.min.js"></script>
Do not use <script type="module">. Do not add any other external library, font, or CDN.
HanziWriter automatically fetches real stroke data for any Chinese character from its own
public data source the first time that character is used — do not invent or embed stroke
coordinates yourself, and do not build your own canvas drawing system; let the library
handle rendering the character and its writing board.

## CHARACTER DATA — starts EMPTY, on purpose
Do NOT embed any starter characters. Start with:

const characters = [];

This app has no built-in vocabulary at all — every character must be added later (see the
separate import feature that gets added in another prompt). Design the whole UI around the
possibility that `characters` is empty, especially on first load.

## WRITING BOARD
For the selected character (when one exists), create (destroying any previous instance
first) a writer inside a container div sized around 300x300px:

const writer = HanziWriter.create('character-target', character, {
  width: 300,
  height: 300,
  padding: 8,
  showOutline: true,
  strokeAnimationSpeed: 1,
  delayBetweenStrokes: 300
});

Wrap the container in a card using the visual style below. You may add a light decorative
grid behind it with plain CSS (a cross and two diagonals, like traditional Chinese
calligraphy practice paper) purely for looks — this is optional and cosmetic only; the
library handles all actual stroke rendering and checking on its own.

## EMPTY STATE (this matters a lot, since the app starts with zero characters)
- If `characters` is empty, do NOT try to create a writer or show the practice controls at
  all. Instead show a friendly Thai message in the main area, something like "ยังไม่มีคำศัพท์
  ในแอปนี้ กรุณาเพิ่มคำศัพท์ก่อนเริ่มฝึกเขียน" and nothing else broken or blank around it.
- The character grid area, pronunciation button, stroke-order button, and quiz button must
  all be hidden or disabled while there are zero characters — never call any HanziWriter
  method with an undefined character.
- As soon as characters exist (this will happen once an import feature is added in a later
  prompt and the person actually imports something), the empty-state message disappears and
  the first character is selected automatically.

## CONTROLS (only relevant once at least one character exists)
- A grid of small buttons, one per character in the data, each showing the character and
  its pinyin. Tapping one selects it and recreates the writer for that character. The
  currently selected character is visually highlighted.
- An info card showing the selected character large, its pinyin, Thai meaning and one
  example word.
- "🔉 ออกเสียง" plays the pronunciation of the selected character using the browser's
  built-in Web Speech API, nothing external:

  function speak(hanzi) {
    if (!window.speechSynthesis) return;
    const utterance = new SpeechSynthesisUtterance(hanzi);
    utterance.lang = 'zh-CN';
    window.speechSynthesis.speak(utterance);
  }

  Do NOT use fetch() or any online TTS service for this — Web Speech API is built into
  the browser already and needs no extra library or network request of its own.
- "▶ เล่นลำดับสโตรก" calls writer.animateCharacter() to show the real stroke order.
- "✏️ ฝึกเขียน" starts writer.quiz({ onCorrectStroke, onMistake, onComplete }):
  - onCorrectStroke: give brief positive Thai feedback for that stroke.
  - onMistake: show a brief Thai hint and let the student try that same stroke again;
    never block or freeze.
  - onComplete: show a Thai completion message (e.g. "เขียนครบแล้ว!").
  This built-in quiz already validates stroke shape and order against real data — do not
  build a separate custom scoring system on top of it.
- Everything must work equally well on desktop and on a phone screen, with tap targets big
  enough for a finger. On narrow screens the character grid may wrap to multiple lines.

## VISUAL STYLE
Warm paper-like background (approx #f5f1eb), white rounded cards (radius ~24–32px), soft
shadows, a red accent for primary actions (approx #c31f2d) and a dark green for secondary
actions (approx #173f35).

## NEVER BREAK
If the CDN script fails to load (e.g. no internet), detect this and show a clear Thai
message explaining that this app needs an internet connection, instead of a blank white
screen or a silent freeze. Anywhere else something can go wrong, show a short Thai message
instead. I cannot debug code myself.
