Prompt 1

Build me a Chinese vocabulary discovery game as ONE self-contained HTML file.
I am a Chinese language teacher. I cannot write or read code.

## OUTPUT REQUIREMENT
A single .html file containing all HTML, CSS and JavaScript.
I will double-click it to open it in a browser. No server, no install, no build step.

## HARD RULES — breaking any of these makes the game fail completely
- The ONLY external resources allowed, exactly as given, placed in <head>. No other
  library — no React, Vue, jQuery, icon set, or animation library:
    <script src="https://cdn.tailwindcss.com"></script>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link href="https://fonts.googleapis.com/css2?family=Quicksand:wght@500;700&family=Noto+Sans+SC:wght@700&display=swap" rel="stylesheet">
  These are classic script/link tags, not modules, so they load fine from file:// —
  but the computer needs internet the first time the file opens.
- No <script type="module">, no import, no export — ES modules are blocked on file://.
- No fetch() or XMLHttpRequest anywhere. The only network call in the whole app besides
  the head tags above is the pronunciation audio URL further down, via new Audio(),
  never fetch().
- All game data is embedded below — load nothing else from the network.
- All UI text (titles, buttons, messages) in THAI. Chinese words stay Chinese, with pinyin.

## WHAT THIS GAME IS
"ผสมธาตุ" (combine the elements), like Infinite Craft. The player starts with only
four elements and discovers new things by combining what they already have. Anything
they discover can be combined again, so the board keeps growing. Think of it as a
chain, not a quiz: there is no wrong answer to punish, only combinations that do
nothing yet.

## HOME SCREEN
A title screen: game name, short one-line description, then a single "เริ่มเล่น"
button into the game board.

## HOW IT WORKS
- The player starts with exactly four cards: 水 火 风 土.
- The player drags one card onto another, or taps two cards in a row on phone.
- If that pair is in the recipe list below, in either order, the result is DISCOVERED:
  show a result card with the new Chinese word, its pinyin, its Thai meaning, a speaker
  button, and the Thai sentence explaining WHY those two things make it. Then the new
  item becomes a permanent card on the board that can be combined again.
- A pair can produce something from an earlier discovery too, for example
  水+火 = 蒸汽, then 蒸汽+沙尘 = 云, then 云+水 = 雨. This chaining is the whole point.
- If the pair is not in the list, show a short Thai message: "ไม่มีคำนั้นๆ" and put the
  cards back. Never freeze, never show an error.
- Count consecutive failed attempts, reset the count on any success. After 3 in a row,
  automatically show a suggestion using ONE pair the player can currently make, for
  example "ลองผสม 水 กับ 火 ดูสิ" — reuse the same "find one makeable pair" logic as the
  hint button below, so failing repeatedly never leaves the player stuck.
- Cards must never overlap. Compute the nearest free position once and place the card
  there. Do NOT write a physics engine and do NOT run an animation loop that keeps
  pushing cards apart, it makes cards jitter and impossible to drag.
- Show progress as "ค้นพบแล้ว 5/45". When all 45 are found, show a celebration screen.
- Save discoveries in localStorage so they survive closing the browser.
- Add a "ยังไม่รู้จะผสมอะไร" hint button, same suggestion logic as above, that reveals ONE pair the player can make right
  now from cards they already own. It never reveals a pair they cannot reach yet.
- Every Chinese word (starting cards and discoveries) has a speaker button that plays
  its pronunciation using this exact function (it is already tested and works from
  file://, trying Google's TTS voice first and falling back to the browser's own voice
  if that request fails, for example when offline):

function speak(hanzi) {
  const url = 'https://translate.google.com/translate_tts?ie=UTF-8'
    + '&q=' + encodeURIComponent(hanzi)
    + '&tl=zh-CN&total=1&idx=0'
    + '&textlen=' + hanzi.length
    + '&client=tw-ob&prev=input&ttsspeed=1';
  new Audio(url).play().catch(() => {
    const u = new SpeechSynthesisUtterance(hanzi);
    u.lang = 'zh-CN';
    speechSynthesis.speak(u);
  });
}

Use new Audio() directly, and only for this one URL. Never use fetch() for it.
