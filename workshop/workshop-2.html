requirement ที่ครูพิมพ์ให้ AI

ครูไม่ต้องเขียนภาษาอังกฤษเอง พิมพ์ความต้องการเป็นภาษาไทยแล้วขึ้นต้นว่า "เขียน prompt เป็นภาษาอังกฤษให้หน่อย requirement คือ..." AI จะเรียบเรียงเป็น prompt อังกฤษให้ แล้วค่อยเอา prompt นั้นไปสั่งสร้างเว็บอีกที นี่คือ requirement ก้อนเดียวที่ครอบทั้งเว็บนี้:

"เขียน prompt เป็นภาษาอังกฤษให้หน่อย requirement คือผมต้องการสร้าง website HTML ไฟล์เดียว
เป็นเกมเรียนคำศัพท์ภาษาจีน มี 2 เกมอยู่ในเว็บเดียวกัน

เกมแรก ใช้คำศัพท์ตามไฟล์ที่แนบไป เล่นได้ 2 แบบ คือจับคู่คำจีนกับความหมายภาษาไทย และผสมตัวอักษรสองตัวให้เป็นคำ เช่น 老 + 师 = 老师

เกมที่สอง เป็นเกมรูปแบบผสมคำเหมือน infinite craft โดยมีตัวตั้งต้นเป็นดิน น้ำ ลม ไฟ แล้วให้คุณอ้างอิงจากการเกิดตามหลักการวิทยาศาสตร์ ใช้สูตรตามไฟล์ที่แนบไป

มีปุ่มฟังเสียงอ่าน มีระบบเลเวลบอกว่าตอนนี้อยู่ระดับไหนแล้ว ขอเป็นยศแบบจีนโบราณที่ได้มาจากการสอบ
เปิดด้วยการดับเบิลคลิกได้เลย ไม่ต้องลงโปรแกรมอะไร ผมเขียนโค้ดไม่เป็น พังแล้วแก้เองไม่ได้"

คำที่ใช้ในประโยคข้างบน แปลว่าอะไร รู้ไว้แล้วเอาไปสั่งงานอื่นต่อได้

คำหมายความว่า
website HTML ไฟล์เดียวไฟล์หน้าเว็บ 1 ไฟล์ที่มีทุกอย่างอยู่ในตัว ดับเบิลคลิกแล้วเปิดในเบราว์เซอร์ได้เลย ถ้าไม่บอกคำนี้ AI จะให้โปรเจกต์หลายไฟล์ที่ต้องลงโปรแกรมก่อน
ไฟล์ที่แนบไปไฟล์ Word หรือ PDF ที่ลากไปวางในช่องแชท AI อ่านได้ ไม่ต้องพิมพ์คำศัพท์ซ้ำ

ตัวตั้งต้นของที่ผู้เล่นมีตั้งแต่เริ่ม ก่อนจะไปหาของอื่นเอง เกมนี้คือ ดิน น้ำ ลม ไฟ
อ้างอิงจากหลักการวิทยาศาสตร์สั่งให้ทุกสูตรมีเหตุผลจริงกำกับ ไม่ใช่ผสมมั่ว เช่น น้ำ+ไฟ ได้ไอน้ำ เพราะความร้อนทำให้น้ำระเหย
ระบบเลเวลระดับที่บอกว่าเล่นมาไกลแค่ไหน เกมนี้ขอเป็นยศจากการสอบจอหงวนของจีน แทนที่จะเป็น Level 1 Level 2

Prompt 1

Build me a Chinese vocabulary game as ONE self-contained HTML file.
I am a Chinese language teacher. I cannot write or read code.

## OUTPUT REQUIREMENT
A single .html file containing all HTML, CSS and JavaScript.
I will double-click it to open it in a browser. No server, no install, no build step.

## HARD RULES — breaking any of these makes the game fail completely
- No external libraries. No <script src="https://...">. No React, Vue, Tailwind CDN, jQuery.
  Plain vanilla JavaScript only.
- Do NOT use <script type="module">, and do NOT use import or export.
  The file runs from file:// where ES modules are blocked and nothing would execute.
- Do NOT use fetch() or XMLHttpRequest on local files. It always fails with
  "TypeError: Failed to fetch" on file://.
- All vocabulary data is embedded below. Do not load any code, library, font or
  data from the network. The ONLY network request allowed in the whole app is the
  pronunciation audio URL given further down.
- All UI text (titles, buttons, messages, labels) must be in THAI.
  The vocabulary itself stays Chinese, shown with its pinyin. Code and comments are English.

## HOME SCREEN
The app opens on a home screen with a title and two large buttons:
  1. "จับคู่คำศัพท์"  -> matching mode (build this now)
  2. "ผสมคำ"          -> combine mode (show the button, but it opens a screen
                          that just says "เร็ว ๆ นี้" for now)
Every screen has a way back to the home screen.

## MATCHING MODE (build this fully)
- One round shows 5 Chinese words on the left and their 5 Thai meanings on the right,
  shuffled. The player taps a Chinese word then taps a Thai meaning.
- Correct pair: both lock in green with a short animation, and the pinyin is revealed.
- Wrong pair: both flash red briefly and unselect. Never block the player, never show a
  dead end.
- When all 5 pairs are matched, show a result card with the score and a
  "รอบต่อไป" button that starts a new round with 5 different words.
- Track how many of the 38 words the player has matched correctly at least once,
  and show it as "จำได้แล้ว 12/38" on the home screen.
- Save that progress in localStorage so it survives closing the browser.
- Every Chinese word has a speaker button that plays its pronunciation using this
  exact function (it is already tested and works from file://):

function speak(hanzi) {
  const url = 'https://translate.google.com/translate_tts?ie=UTF-8'
    + '&q=' + encodeURIComponent(hanzi)
    + '&tl=zh-CN&total=1&idx=0'
    + '&textlen=' + hanzi.length
    + '&client=tw-ob&prev=input&ttsspeed=1';
  new Audio(url).play().catch(() => {
    const u = new SpeechSynthesisUtterance(hanzi);
    u.lang = 'zh-CN';
    speechSynthesis.speak(u);
  });
}
